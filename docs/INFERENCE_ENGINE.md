# DIGITAL FOSSIL: Deterministic Inference Engine & Confidence Scoring

## 1. Core Mandate

The central innovation of Digital Fossil is **evidence-backed activity reconstruction with explicit uncertainty**. The system NEVER invents evidence, NEVER fabricates unrecorded intermediate steps, and NEVER presents probabilistic inferences as established facts.

---

## 2. Multi-Factor Correlation Formula

When comparing two events $E_1$ and $E_2$, the correlation score $S(E_1, E_2)$ is calculated deterministically with transparent weights:

$$S_{\text{composite}} = w_t S_t + w_{\text{name}} S_{\text{name}} + w_{\text{seq}} S_{\text{seq}} + w_{\text{dir}} S_{\text{dir}} + w_{\text{ext}} S_{\text{ext}} + B_{\text{proc}}$$

Where:
- $w_t = 0.30$ (Temporal Proximity)
- $w_{\text{name}} = 0.25$ (Filename Similarity)
- $w_{\text{seq}} = 0.20$ (Sequence Order Compatibility)
- $w_{\text{dir}} = 0.15$ (Directory Locality)
- $w_{\text{ext}} = 0.10$ (Extension Compatibility)
- $\sum w = 1.00$

### Factor Breakdown:
1. **Temporal Proximity ($S_t$)**:
   Exponential decay based on absolute time difference $\Delta t$:
   $$S_t = \exp\left(-\frac{\ln(2) \cdot \Delta t}{60}\right)$$
   A 0-second gap yields 1.0; a 60-second gap yields 0.5; large gaps (>120s) decay asymptotically towards 0.
2. **Filename Similarity ($S_{\text{name}}$)**:
   Levenshtein-based sequence matcher ratio on base names (ignoring extensions and common suffixes like `_copy`, `-converted`). For example, `report.docx` and `report.pdf` achieve $S_{\text{name}} = 1.0$.
3. **Sequence Order Compatibility ($S_{\text{seq}}$)**:
   Encodes valid lifecycle progression:
   - `FILE_CREATED` $\to$ `FILE_MODIFIED`: 0.90
   - `FILE_MODIFIED` $\to$ `FILE_MOVED`: 0.85
   - `PROCESS_STARTED` $\to$ `FILE_CREATED`: 0.85
   - Reverse transitions receive substantial penalties.
4. **Directory Locality ($S_{\text{dir}}$)**:
   Identical folder paths = 1.0; parent/child subfolder = 0.60; disjoint paths = 0.15.
5. **Extension Compatibility ($S_{\text{ext}}$)**:
   Document derivations (`docx` $\to$ `pdf`, `png` $\to$ `zip`) = 0.80; identical extensions = 1.0; incompatible = 0.20.
6. **Process Continuity Bonus ($B_{\text{proc}}$)**:
   $+0.05$ bonus if both events are executed by the same process image.

## 3. Evidence Confidence Scoring

Unlike conventional classifiers that present pseudo-probabilities, Digital Fossil calls its metric **"Evidence Confidence"**:

$$C = \text{clamp}\Big( 0.65 \cdot S_{\text{composite}} + 0.35 \cdot P_{\text{ML}} + B_{\text{proc}} - \sum \text{Penalties},\; 0.05,\; 0.95 \Big)$$

### Explicit Penalties:
- **Missing Telemetry Penalty**: $-0.12$ per expected intermediate step that is absent from records (e.g. no converter utility captured).
- **Contradictory Evidence Penalty**: $-0.20$ per contradictory artifact (e.g. lifecycle inversion where a file is recorded as modified after deletion).
- **Time Gap Penalty**: $-0.10$ if gap exceeds 90 seconds.

### Qualitative Classification:
- **HIGH ($\ge 0.75$)**: Strong evidence convergence across temporal, naming, and structural features.
- **MEDIUM ($0.45 \le C < 0.75$)**: Suggestive patterns observed, but intermediate custody steps are unrecorded.
- **LOW ($< 0.45$)**: Weak or conflicting evidence; relationship is speculative.
- *Note: Confidence is strictly bounded below 1.00 because digital activity reconstruction possesses inherent uncertainty.*

---

## 4. Mandatory Uncertainty Statements

Every hypothesis generated by the inference engine MUST include an **Uncertainty Statement**. For example:
- **Hypothesis**: *"The user may have prepared a source document, exported a corresponding PDF copy, and relocated the artifact prior to opening a mail client."*
- **Uncertainty Statement**: *"No direct file conversion process or email dispatch event was recorded in evidence. Document transformation is an inference based on metadata compatibility."*
